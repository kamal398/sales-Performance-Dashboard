Sales Performance Dashboard | Power BI

 Overview
This project is a Power BI dashboard that analyzes sales performance using key business metrics.

 Key Features
- Total Sales, Profit, and Cost KPIs
- Profit % and Year-over-Year (YoY) growth analysis
- Sales analysis by region, country, and product category
- Interactive filters and slicers for dynamic insights

 Tools Used
- Power BI
- DAX (Data Analysis Expressions)

 Insights
- Identified top-performing regions and products
- Analyzed profit trends and growth patterns
